# Plano de Implementação — Melhorias para Submissão do Artigo

## Contexto

O artigo atual (`artigo/conteudo.tex`, tag `paper-v1.1-final`) já possui uma base sólida:
validação cruzada agrupada com GroupKFold, auditoria de leakage (25 eventos, 0 overlaps), 611 execuções de estabilidade (60.045 comparações pareadas), experimento FairFace com 4 cenários e controle sintético (AUC = 1,000; Jaccard = 0,000). 

O objetivo agora é transformar esse caso em uma **contribuição metodológica geral**, posicionada para FAccT, e preencher as lacunas experimentais e conceituais apontadas pelos revisores.

---

## Mudança de Framing (Textual — sem código)

O enquadramento central deve migrar de:
> "AUC alta não significa criminalidade."

para:
> **Correct out-of-sample evaluation does not establish construct validity when the target itself is endogenously generated from the representation being evaluated.**

Essa mudança vale para qualquer domínio (risco, personalidade, empregabilidade, emoção, confiança), tornando a contribuição geral, não apenas crítica a um experimento específico.

## Entrega 2 — FairFace Pareado, Replicado e com Decomposição de Variância

**Localização:** `scripts/`, `face_profile_ml/`, `artigo/conteudo.tex` — Seção 2.6 + Resultados

### O que falta hoje
- O desenho atual tem 4 cenários com 1 seed cada — não decompõe composição vs. amostragem vs. seed vs. k.
- O texto já admite isso como limitação (Seção 5): *"Uma extensão adequada exige 50–100 replicações independentes ou um desenho pareado."*

### Tarefas de código

#### 2a. Novo script de amostragem pareada
- [ ] **Criar `scripts/run_fairface_replicated.py`** com:
  - Parâmetros: `--n-replications 50 --seeds-per-rep 5 --k-values 32,64,128 --scenarios A,B,C,D`.
  - Lógica: para cada replicação `r`, sortear um **núcleo fixo** de imagens compartilhado entre todos os cenários (~70% do N) e complementar com sorteio independente por cenário para atingir as quotas. Isso isola parcialmente efeito de composição do efeito de amostragem.
  - Salvar por execução: `sample_id`, `scenario`, `replication`, `seed`, `k`, `cluster_label`, `is_target`, `score`, `prob_calibrated`, `distance_to_centroid`, `fairface_category`.
  - Output: `artifacts/fairface_replicated/oof_predictions.parquet` + `variance_decomposition.csv`.

#### 2b. Decomposição de variância (ANOVA/bootstrap)
- [ ] **Criar `face_profile_ml/variance_decomposition.py`** com:
  - Função `decompose_variance(df, outcome_col, factors)` usando ANOVA de efeitos fixos ou bootstrap permutacional.
  - Fatores: `scenario` (composição), `replication` (amostragem), `seed` (inicialização), `k` (hiperparâmetro).
  - Retorna `VarianceDecompositionResult` com frações explicadas por cada fator para AUC, Jaccard e tamanho do alvo.

### Tarefas de texto (LaTeX)
- [ ] Substituir Seção 2.6 e Tabela 4 pelos novos resultados com:
  - Tabela de decomposição de variância (composição % vs. amostragem % vs. seed % vs. k %).

## Entrega 3 — Ablação das Definições do Cluster-Alvo (Target Rule Ablation)

**Localização:** `face_profile_ml/`, `scripts/`, `artigo/conteudo.tex`

### O que falta hoje
- O pipeline usa exclusivamente `largest_cluster` (regra hardcoded em `cli.py` linha 201 e Apêndice A.2).
- O artigo menciona ablação como trabalho futuro (Seção 5): *"ablar a regra do alvo"*, mas não a executa.

### Tarefas de código

#### 3a. Módulo de regras de seleção de alvo
- [ ] **Criar `face_profile_ml/target_rules.py`** com as seguintes funções:
  ```python
  def largest_cluster(labels, centroids, X) -> int
  def most_compact_cluster(labels, centroids, X) -> int   # menor intra-cluster variance
  def most_separated_cluster(labels, centroids, X) -> int # maior distância ao centroide global
  def random_cluster(labels, centroids, X, rng) -> int    # controle nulo
  def central_cluster(labels, centroids, X) -> int        # mais próximo ao centroide global
  def outlier_cluster(labels, centroids, X) -> int        # mais distante ao centroide global
  ```
  - Cada função retorna o índice do cluster selecionado.

#### 3b. Script de ablação sistemática
- [ ] **Criar `scripts/run_target_ablation.py`** com:
  - Para cada regra × seed (50) × k (32, 64, 128): executar GroupKFold completo e salvar métricas OOF.
  - Output principal: `artifacts/ablation/ablation_results.csv` com colunas `rule, seed, k, fold, auc, pr_auc, jaccard_vs_largest, jaccard_pairwise, prevalence`.
  - Output secundário: `artifacts/ablation/incompatibility_matrix.csv` — para cada par de regras, o Jaccard mediano dos conjuntos-alvo resultantes.

#### 3c. Integrar ablação no pipeline principal
- [ ] Adicionar argumento `--target-rule {largest,compact,separated,random,central,outlier}` ao subcomando `fit` em `face_profile_ml/cli.py`.

### Tarefas de texto (LaTeX)
- [ ] Adicionar subseção "Ablação da Definição do Alvo" em Resultados com:
  - Tabela: regra × AUC mediana × Jaccard-vs-largest mediano × Jaccard-pairwise (entre diferentes regras).
  - Resultado-chave a reportar: quantas definições mutuamente incompatíveis (Jaccard < 0.1 entre si) atingem AUC > 0.85?
  - Boxplot por regra (nova figura para substituir/complementar image2.png).
