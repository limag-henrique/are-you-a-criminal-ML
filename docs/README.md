# Documentação do Projeto

Esta pasta centraliza os relatórios metodológicos, protocolos de auditoria de equidade, planos de experimentação e versões do manuscrito acadêmico.

## Estrutura de Diretórios

- **`manuscript/`**: Versões do artigo/monografia em formato Word (`.docx`).
- **`protocols/`**:
  - `fairness_evaluation_protocol.md`: Protocolo detalhado para auditoria de FMR/FNMR por subgrupos e coortes demográficas.
  - `external_benchmark_inventory.md`: Inventário e especificações dos benchmarks externos utilizados (ex: BFW, FairFace).
  - `final_report.md`: Relatório metodológico consolidado e resultados das avaliações.
- **`superpowers/`**:
  - `plans/`: Planos formais de execução de experimentos científicos.
  - `specs/`: Especificações técnicas e critérios de aceitação.
- **`similaridade.png`**: Demonstração visual da interface do aplicativo de similaridade facial.
